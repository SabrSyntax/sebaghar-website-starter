# SebaGhar Static Website

## ফাইল
- `index.html` — পেজের কনটেন্ট ও HTML
- `style.css` — সব ডিজাইন, কালার ও responsive layout
- `script.js` — মোবাইল মেনু ও বর্তমান বছর
- `assets/` — লোগো ও favicon রাখার ফোল্ডার

## আপনার লোগো যোগ করার নির্দেশনা
1. আপনার মূল/হেডার লোগোর PNG ফাইলের নাম দিন `logo.png`।
2. সেটি `assets` ফোল্ডারের মধ্যে রাখুন: `assets/logo.png`
3. ফেভিকন লোগোর PNG ফাইলের নাম দিন `favicon.png` এবং রাখুন `assets/favicon.png`।
4. favicon-এর জন্য বর্গাকার 512×512 PNG ভালো; মূল লোগো স্বচ্ছ ব্যাকগ্রাউন্ডের PNG হলে আরও ভালো দেখাবে।
5. ফাইলের নাম বা ফোল্ডার বদলালে `index.html`-এ থাকা সংশ্লিষ্ট path-ও বদলাতে হবে।

এই প্যাকেজে আপনার আপলোড করা লোগো বসানো নেই; আপনার নির্দিষ্ট লোগো ফাইল আপলোড করে উপরের নাম অনুযায়ী রাখতে হবে।

## চালানোর নিয়ম
`index.html` ফাইল ব্রাউজারে খুললেই দেখা যাবে। অনলাইনে প্রকাশ করতে তিনটি ফাইল এবং `assets` ফোল্ডারসহ একই ফোল্ডার-স্ট্রাকচার হোস্টিংয়ে আপলোড করুন।

## Google Maps
Google Business Profile verification সম্পূর্ণ হলে `index.html`-এ `Google Maps` লেখা HTML comment অংশটি খুঁজুন। ম্যাপ সেকশন চালু করতে comment-এর `<!--` এবং `-->` সরিয়ে দিন এবং iframe-এর `src`-এ Google Maps থেকে পাওয়া embed URL বসান। তার আগে অংশটি লুকানোই থাকবে।
