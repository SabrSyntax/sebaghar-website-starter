# SebaGhar | সেবাঘর

**Your Needs, Our Care.**

SebaGhar is a responsive, Bengali-first website for a local multipurpose service centre operated under the existing business identity of **ANSARI DIGITAL WORLD**, with ANSARI INDIA as the Udyam enterprise name.

The website introduces SebaGhar's digital services, everyday essentials, stationery, books, and other useful products. Its purpose is to make information about the business and its services easily accessible to customers across desktop and mobile devices.

**Live Website:** https://sebaghar.ansariindia.com

---

## ✨ Features

- **Responsive Design** — Optimised for desktop, tablet, and mobile screens.
- **Bengali-First Interface** — Designed primarily for Bengali-speaking customers.
- **Modern UI** — Clean layouts, rounded components, subtle shadows, and a consistent blue-and-white visual identity.
- **Service Overview** — Dedicated sections describing digital services, document assistance, banking-related services, bill payments, printing, ticket-booking assistance, stationery, books, and essential products.
- **WhatsApp Integration** — Direct links for customer communication.
- **WhatsApp Channel Updates** — A prominent notice encourages visitors to follow the channel for service updates.
- **Mobile Navigation** — An interactive navigation menu for smaller screens.
- **Contact Information** — Quick access to the business phone number, email, website, and location information.
- **Future Map Integration** — A reserved section for adding an embedded Google Map when appropriate.
- **Lightweight Architecture** — Built with standard HTML, CSS, and vanilla JavaScript without a frontend framework.

## 🛠️ Technology Stack

- **HTML5** — Page structure and content.
- **CSS3** — Layout, styling, responsive behaviour, and visual effects.
- **Vanilla JavaScript** — Mobile navigation and small dynamic elements.
- **Google Fonts** — Hind Siliguri and Inter typography.
- **Vercel** — Hosting and deployment.

No frontend framework, package manager, or build step is required for the current static implementation.

## 📁 Project Structure

```text
SebaGhar/
├── index.html       # Main webpage and content
├── style.css        # Styling and responsive layouts
├── script.js        # Navigation and interactive behaviour
├── assets/          # Logo, favicon, and other static assets
└── README.md        # Project documentation
```

The `assets/` directory contains the website's static resources. Keep asset filenames and relative paths consistent with their references in the HTML.

## 🎨 Design Principles

The website follows a simple visual system:

- **Primary colour:** Blue
- **Background:** White and light blue
- **Typography:** Hind Siliguri for Bengali content and Inter for supporting text
- **Layout:** Responsive sections, service cards, clear calls to action, and accessible navigation
- **Branding:** Preserve the existing SebaGhar logo, brand identity, and established tagline.

The design prioritises readability, usability, and a consistent experience across screen sizes.

## ⚙️ Development Notes

- The project is a static website and does not currently require a backend or database.
- Keep HTML, CSS, and JavaScript in their existing separate files.
- Use relative paths for local stylesheets, scripts, and assets.
- Preserve responsive behaviour when modifying layouts or components.
- Ensure navigation links, telephone links, email links, and external URLs remain valid.
- Test changes on both desktop and mobile viewports.
- Avoid introducing unnecessary dependencies for functionality that can be handled with standard HTML, CSS, or JavaScript.
- Keep the website lightweight and maintainable.

## 🚀 Deployment

The project is maintained in a public GitHub repository and is intended for deployment through Vercel.

The root directory contains `index.html`, which serves as the website's entry point. The current implementation can be deployed as a static site without a build command.

Ensure that all required files and the `assets/` directory are committed to the repository before deployment.
